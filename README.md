# Country Finder

A modern Angular application to search, explore and view detailed information about countries of the world.

## Features

- Search countries by name
- Filter by region / continent
- View detailed country information (capital, population, currencies, languages, borders, flags, etc.)
- Responsive design (mobile + desktop)
- Client-side routing with parameterized routes
- Loading states & error handling
- Modern Angular architecture (Signals + standalone components)

## Tech Stack

- **Angular** 21
- Signals (reactive primitives)
- RxJS (Observables)
- HttpClient (for REST API calls)
- Angular Router + ActivatedRoute
- Standalone Components & lazy loading
- Tailwind + DaisyUI
- PoweredBy [REST Countries API](https://restcountries.com/)

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/Diego3128/country-spa.git

cd country-spa

# 2. Install dependencies
npm install

# 3. Run the development server
npm start
```
